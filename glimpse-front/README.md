# Glimpse frontend

React + Vite + TypeScript frontend for the Glimpse media search app.

## Structure

- `src/pages/` — Search, People, Person Detail, Favorites, Collections, Saved Searches, Index Manager, Settings, Onboarding
- `src/components/` — shared UI, layout, search widgets, image viewer, video player
- `src/contexts/` — app-wide state (onboarding, models, indexing, search)
- `src/lib/` — API client and shared utilities
- `public/` — static assets

## Stack

- React 18, TypeScript, Vite
- Tailwind CSS + shadcn/ui components
- Lucide icons
